# SellerAI 全口径成本账本（成本部·权威版）

> 成本部职责：把所有「看不见的扣点」算进每一笔收入。
> 口径：先 USD 拆解，再按 $1≈¥7.10 折 CNY（实际汇率每日浮动，提现点到账更低）。
> 费率来源：Gumroad 公开费率 10% 平台费 + Stripe 穿透 2.9%+$0.30；国内税为电商个体户/小微主流合规口径。

## 一、单笔 $19.90 订阅的真实到手拆解（无联盟佣金版）

| 环节 | 计算 | USD | 占毛额 |
|------|------|-----|--------|
| 毛收入 | — | $19.90 | 100% |
| − Gumroad 平台费 10% | 19.9×10% | −$1.99 | 90.0% |
| − 支付处理费 2.9%+$0.30 | 0.577+0.30 | −$0.88 | 85.6% |

| − 国内税预备（个体户综合税负≈2.9%） | 19.9×2.9% | −$0.58 | 81.1% |
| − API 成本（中度 150 次×¥0.006≈¥0.90） | ÷7.1 | −$0.13 | 80.4% |
| **净留存/月** | | **≈ $16.0** | **≈ 80%** |

> 折合人民币净 ≈ **¥113.6/订阅/月**（毛 $19.9≈¥141.3）。

## 四、国内税收（重点：老板要的「国内税」）

SellerAI 收美元、最终提现到国内个人/对公账户，涉及中国税：

| 主体类型 | 税种 | 实际综合税负 | 适用 |
|----------|------|--------------|------|
| 电商个体户（核定征收） | 增值税1% + 个人经营所得0.6–1% + 附加 | **≈2.9% 完税** | 推荐：年收入<500万，完税后可直接提现，无20%分红税 |
| 小微企业（有限公司） | 企业所得税5%（应税≤300万部分）+ 分红20% | **≈24%**（双重征税） | 不推荐早期 |
| 个人独资（核定） | 个人经营所得5%–35%五级，核定后≈1.8% | 低 | 备选 |

> **成本部建议**：以「电商个体户 + 税收洼地核定征收」主体收美元，综合税负≈2.9%，比有限公司省 20+ 个点。
> 注意：2026 年金税四期 + 平台涉税信息报送已趋严，必须合规申报，不能隐匿美元收入。
