# 🌐 域名绑定指南

> 买了域名不知道怎么绑到 Vercel？看完这篇你就会了。全程 5 分钟。

---

## 前提条件

- 你已经有一个域名（Namecheap、阿里云、腾讯云、GoDaddy 买的都行）
- 你已经把项目部署到了 Vercel（没部署？先看 `README.md`）

---

## 一、在 Vercel 添加域名

1. 打开 Vercel 控制台 → 进入你的前端项目
2. 点顶部菜单「**Settings**」
3. 左侧菜单找到「**Domains**」
4. 在输入框里填你的域名，比如 `www.sellerai.com` 或 `sellerai.com`
5. 点「**Add**」

Vercel 会告诉你需要添加什么样的 DNS 记录。**先别关这个页面，下一步要用。**

---

## 二、去域名管理后台添加 DNS 记录

### 情况 A：你用根域名（`sellerai.com`）访问

Vercel 会提示你添加一条 **A 记录**。

| 类型 | 主机记录（Name/Host） | 记录值（Value） |
|------|----------------------|-----------------|
| A | @ | `76.76.21.21` |

照着填进去就好。`@` 在某些平台写成「空」或留空。

### 情况 B：你用 `www.` 开头（`www.sellerai.com`）访问

Vercel 会提示你添加一条 **CNAME 记录**。

| 类型 | 主机记录（Name/Host） | 记录值（Value） |
|------|----------------------|-----------------|
| CNAME | www | `cname.vercel-dns.com` |

### 情况 C：你既要根域名又要 www

两条一起加：

| 类型 | 主机记录（Name/Host） | 记录值（Value） |
|------|----------------------|-----------------|
| A | @ | `76.76.21.21` |
| CNAME | www | `cname.vercel-dns.com` |

> 强烈推荐两条都加。加了之后不管用户打 `sellerai.com` 还是 `www.sellerai.com` 都能访问到你的网站。

---

## 三、各平台操作位置速查

### Namecheap

1. 登录 → Dashboard → 找到你的域名 → 点「**Manage**」
2. 点「**Advanced DNS**」标签页
3. 点「**Add New Record**」→ 按上面的表格填
4. TTL 选「Automatic」就行
5. 点绿色的「✓」保存

### 阿里云（万网）

1. 登录 → 控制台 → 域名 → 找到你的域名 → 点「**解析**」
2. 点「**添加记录**」
3. 按上面的表格填
4. 点「**确认**」

### 腾讯云（DNSPod）

1. 登录 → 控制台 → 域名管理 → 找到你的域名 → 点「**解析**」
2. 点「**添加记录**」
3. 按上面的表格填
4. 点「**保存**」

### GoDaddy

1. 登录 → 我的产品 → 域名 → 找到你的域名 → 点「**DNS**」
2. 点「**添加**」→ 按上面的表格填
3. TTL 选「1 小时」或默认
4. 点「**保存**」

---

## 四、回到 Vercel 验证

添加完 DNS 记录后，回到 Vercel 的 Domains 页面，它会自动检测。

- 显示 **✅ Valid Configuration** → 搞定了，等生效就行
- 显示 **⚠️ 配置有误** → 检查上一步的 DNS 记录有没有填错

---

## 五、等多久生效？

| 时间 | 说明 |
|------|------|
| 1-5 分钟 | 大部分情况下已经生效了，刷新试试 |
| 30 分钟 | 还没好就再等等，有些网络服务商响应慢 |
| 最长 48 小时 | DNS 全球生效的理论最长时间 |

> 实测：90% 的情况在 5 分钟内就生效了。别急，喝杯水再来看。

想知道生效了没？打开命令提示符（Win+R → 输入 `cmd` → 回车），输入：

```
nslookup 你的域名.com
```

如果返回的 IP 是 `76.76.21.21`，就说明已经生效了。

## 六、SSL 证书（HTTPS）

**好消息：你什么都不用做。**

Vercel 会自动帮你申请 SSL 证书，域名生效后 1-2 分钟内 HTTPS 就自动配好了。

你只需要确认用户打开的是 `https://` 开头就行（Vercel 会自动把 `http://` 跳转到 `https://`）。

绿锁图标 ✅ 自动出现 ✅

## 七、常见问题

### Q：加了 DNS 记录很久了还是打不开？

1. 确认 DNS 记录没填错（对照上面的表格，一个字符都不能错）
2. 用手机流量试一下（WIFI 和流量可能解析结果不同）
3. 清除浏览器缓存：Ctrl + Shift + Delete → 选「缓存的图片和文件」→ 清除
4. 还不行就等。DNS 就是玄学，最长 48 小时，但基本不会这么久

### Q：能不能同时绑多个域名？

能。在 Vercel Domain 页面里继续 Add 就行。每个域名都要照上面的步骤配 DNS。

### Q：原来的 `xxx.vercel.app` 还能用吗？

能。绑了域名之后，原来的 Vercel 免费域名照样能用，两个地址同时生效。

### Q：我想换个域名怎么办？

1. 在 Vercel Domain 页面删掉旧域名
2. 等旧域名的 DNS 记录也删掉（在域名后台删）
3. 从头按这个指南给新域名配一遍
