# 📋 每周维护清单

> 每周花 **15 分钟**检查一遍，保证你的 AI 网站不翻车。

---

## 什么时候做？

**每周五下午**，或者每周任意固定一天。形成习惯就不会忘。

---

## 📝 检查清单

每完成一项，在前面打勾 ✅

---

### 1️⃣ 网站能不能打开？（2 分钟）

- [ ] 打开你的网站，看首页能不能正常加载
- [ ] 手机上也打开试一下，确认移动端正常
- [ ] 如果绑了域名，试试带 `www` 和不带 `www` 两个地址

> 打不开？→ 看下面「异常排查一：网站打不开」

---

### 2️⃣ AI 能不能正常回答？（3 分钟）

- [ ] 在聊天框输入「你好」，AI 是否回复
- [ ] 输入一个真实问题（比如「帮我写个手机壳的产品标题」），AI 是否正常回复
- [ ] 回复速度是不是在 5-10 秒以内
- [ ] 回复内容是不是正常的（不是乱码、不是报错信息、不是只回复一半）

> AI 不回？→ 看下面「异常排查二：API 返回错误」

---

### 3️⃣ DeepSeek 余额够不够？（1 分钟）

- [ ] 打开 https://platform.deepseek.com → 登录 → 看首页余额
- [ ] 余额小于 2 块钱？马上去充值（最低充 5 块）
- [ ] 顺便看一眼「用量统计」，有没有异常暴涨的调用量

> 余额没了 AI 就不会回答了。保持余额 5 块钱以上。

---

### 4️⃣ Vercel 部署状态正常吗？（1 分钟）

- [ ] 打开 https://vercel.com → 登录 → Dashboard
- [ ] 前端项目状态是 **Ready**（绿色）→ 不是的话点进去看错误日志
- [ ] 后端项目状态是 **Ready**（绿色）→ 不是的话点进去看错误日志
- [ ] 最近有没有失败的部署记录？有的话点进去看原因

> 状态不绿？→ 看具体报错信息，通常重新 Deploy 一次就好

---

### 5️⃣ 域名还正常吗？（1 分钟）

- [ ] 域名没过期吧？（去你买域名的地方看一眼）
- [ ] HTTPS 绿锁还在吗？（网站地址栏左边有小锁图标）
- [ ] 域名跳转正常吗？（输 `域名.com` 能自动跳到 `https://域名.com`）

> HTTPS 锁没了？→ Vercel 会自动续，等几分钟就好。如果超过一天还没好，去 Domains 页面看一下。

---

### 6️⃣ 有没有异常情况？（2 分钟）

- [ ] 有没有人反馈网站不好用？→ 记下来，下次升级的时候修
- [ ] 看看浏览器 F12 → Console，有没有红色错误
- [ ] 最近有没有改过代码？改了之后都正常吗？

---

### 7️⃣ 多余：GitHub 代码备份了没？（1 分钟）

- [ ] 最近有没有改过代码但没 push 到 GitHub？
- [ ] GitHub 仓库内容是不是最新的？

> 代码丢了哭都来不及。改完就 push！

---

### 总用时

| 检查项 | 预计时间 |
|--------|---------|
| 网站能不能打开 | 2 分钟 |
| AI 能不能回答 | 3 分钟 |
| DeepSeek 余额 | 1 分钟 |
| Vercel 状态 | 1 分钟 |

## 🔧 异常情况排查

### 异常一：网站打不开

**现象：** 打开网址白屏、404、加载转圈一直不停

**按顺序试：**

1. **等 30 秒再刷新** → Vercel 偶尔抽风，刷新就好
2. **换个浏览器** → 用 Chrome 的无痕模式（Ctrl+Shift+N）打开
3. **用手机流量试** → 排除 WIFI 问题
4. **进 Vercel 看状态** → 项目 Deployments 页面 → 最近一条是不是 Ready？
   - 不是 Ready → 点进去看错误日志，截图发给懂技术的人
   - 是 Ready → 可能是 DNS 有问题
5. **DNS 问题排查** → 打开命令提示符（Win+R → `cmd`），输入 `nslookup 你的域名.com`，看返回的是不是 `76.76.21.21`（Vercel 的 IP）。不是的话，DNS 没配对，回头看 `域名绑定指南.md`
6. **终极方案** → Vercel 项目里 Settings → Domains → 删掉域名 → 等 5 分钟 → 重新 Add，重新配 DNS

---

### 异常二：API 返回错误 / AI 不回复

**现象：** 网页能打开，但发消息后要么没反应，要么显示「网络错误」「服务器错误」

**按顺序试：**

1. **DeepSeek 欠费了** → 去 https://platform.deepseek.com 看余额，低于 0 就充值
2. **环境变量过期** → 有时候 API Key 会失效。去 DeepSeek 后台重新生成一个 Key，在 Vercel 里更新 `DEEPSEEK_API_KEY`，然后 **Redeploy**
3. **后端挂了** → 进 Vercel 后端项目的 Deployments → Runtime Logs，看有没有红色错误
   - 看到 `401 Unauthorized` → API Key 不对或过期
   - 看到 `429 Too Many Requests` → 调用太频繁，被限流了，等几分钟
   - 看到 `503` → DeepSeek 服务器炸了（不常发生），等半小时再试
4. **环境变量没配** → 检查 Settings → Environment Variables，确认变量名对不对（大小写敏感！）
5. **没 Redeploy** → 改了环境变量后必须 Redeploy！这是 90% 问题的根源
6. **CORS 错误** → 这个需要改代码，找懂技术的人处理

---

### 异常三：AI 回复很慢

**现象：** 发消息后要等 20 秒甚至更久才有回复

**排查：**
- DeepSeek 高峰期可能慢（工作日上午 10 点、下午 3 点），换一个时间试
- 问题太长太复杂也会慢，正常
- Vercel 免费版有冷启动（长时间没人用后第一次访问会慢），刷新重试一次就快了

---

### 异常四：AI 回复不完整 / 乱码

**现象：** AI 说到一半就停了，或者输出了一堆看不懂的东西

**排查：**
- Vercel Serverless 有 10 秒超时限制。太长的回答可能被截断
- 换个简单点的问题试试
- 如果是乱码，可能是模型版本问题，去 DeepSeek 后台切换模型版本

## 终极 SOP：网站挂了，我很慌，怎么办？

别慌，三步走：

1. **先确定是 Vercel 的问题还是 API 的问题**
   - 网站打不开 → Vercel 的问题
   - 网站能打开、AI 不回复 → API 的问题

2. **Vercel 问题** → 看 Deployment Logs，截图，去 Vercel 状态页看是不是官方宕机了：https://www.vercel-status.com

3. **API 问题** → 看 DeepSeek 余额、看 API Key 是不是过期、看环境变量是不是配对了

80% 的问题都能在这三步里解决。剩下 20% 🤷 找技术朋友帮忙。
