## 五、风险提示

⚠️ **两个致命假设：**
1. **选品引擎的 BSR 数据**——现在靠公共爬虫，Amazon 反爬是早晚的事。一旦切 Rainforest API 付费版，单次成本从 ¥0.012 跳到 ¥0.05（涨 4x），月成本从 $0.14 涨到 $0.35/人，毛利率从 88% 降到 86%——仍然成立，但上量到 1000 用户月费用 $350 要关注。
2. **三个功能的 API 调用不加门控的话**——DeepSeek ¥22.45 余额可能被单个攻击者打穿（Resend 同理）。三层都必须加配额 fail-closed。
