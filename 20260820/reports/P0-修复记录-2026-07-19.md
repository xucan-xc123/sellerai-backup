```diff

+   console.error("[gumroad] GUMROAD_WEBHOOK_SECRET not set — refusing all webhooks");

```

## P0-3: Auth Token 明文存数据库 — ✅ 已修复

**文件**:
- `lib/crypto.ts` — 新建
- `app/api/auth/verify-code/route.ts` — 写入时 hash
- `app/api/auth/me/route.ts` — 查询时 hash
- `app/api/generate-listing/route.ts` — 查询时 hash

**问题**: `auth_tokens` 表存原始 token 字符串（`sai_xxx`），未做 hash。数据库泄露即可获取全部有效 token。

**修复**:
1. **新建 `lib/crypto.ts`**: 导出 `sha256(text: string): Promise<string>` 工具函数，使用 Web Crypto API
2. **写入时 hash** (`verify-code/route.ts`): 生成 token 后先 hash 再存入 `auth_tokens.token` 字段，返回客户端的仍是明文 token
3. **查询时 hash** (`me/route.ts`, `generate-listing/route.ts`): 从请求头提取明文 token 后，先用 `sha256()` hash 再查数据库

> ⚠️ **数据库兼容性说明**: 该仓库已验证过的 `auth_tokens` 表中原有 `sai_` 开头的明文 token 需迁移到 hash 值才能继续使用。迁移脚本：
> ```sql
> UPDATE auth_tokens SET token = lower(hex(sha256(token)));
> ```
> 或通过应用写入一次新 token 让旧 token 自动过期（30天）。
