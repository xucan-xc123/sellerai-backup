## 技术架构

```
POST /api/reviewiq/analyze { asin: "B0XXXXXXXXX" }
  → scraper.ts (路由到对应平台)
    → amazon.ts (HTTP请求 + 解析)
      → JSON-LD 解析 (优先，结构数据)
      → Regex fallback (DOM data-hook 属性)
  → ScrapeResult { asin, platform, totalReviews, reviews[], scrapedAt }
```

### 关键设计决策

1. **纯字符串解析**：不使用 cheerio/jsdom 等 Node 原生模块，确保 CF Workers 兼容
2. **JSON-LD 优先**：Amazon 评论页包含 `<script type="application/ld+json">` 结构化数据，优先解析
3. **Regex fallback**：如果 JSON-LD 不可用，使用正则匹配 `data-hook` 属性提取评论块
4. **UA 轮换**：每次请求随机选择 50+ User-Agent 中的一个
5. **指数退避重试**：503/429 时延迟重试，自动更换 UA

## 已知限制

1. **单页爬取**：当前只抓取第一页（通常 10 条评论），多页爬取需要 Day 3 代理池方案
2. **CF Workers 限制**：免费套餐 CPU 时间有限（10ms），大量评论解析可能超时
3. **反爬检测**：Amazon 可能通过 JS Challenge 返回空白页，当前无法处理
4. **variant/media**：暂未提取颜色/尺码变体和图片附件
