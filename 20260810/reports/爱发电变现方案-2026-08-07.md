# 爱发电（Afdian）AI 服务变现方案

> 调研日期：2026-08-07 | 调研人：SellerAI 变现调研员（子Agent）
> 状态：✅ 已完成平台机制调研（web_fetch + web_search）；⚠️ 登录态检查未完成（浏览器导航被 SSRF 策略拦截，非 DNS 问题）

## 一、平台机制摘要（已核实）

### 1. 核心模式：会员制订阅（Patreon 国内版）+ 付费内容 + 打赏
- **月赞助/会员方案（主力）**：创作者自定义多个档位（如 5 元/月、19.9 元/月、99 元/月），粉丝按月订阅，有效期 31 天，可补差价升级。这是平台最核心的变现方式。
- **一次性付费内容/动态**：创作者发布图文/音频/视频动态，可设置"仅某赞助档位可见"或按次付费解锁。
- **打赏**：粉丝可对动态/内容单次打赏。
- **适合卖 AI 服务的方式判断**：
  - ✅ **档位制最合适**——把"AI 文案代写 N 次/月"、"简历优化 2 次/月"打包成会员档位（订阅式，稳定现金流）；
  - ✅ **一次性付费动态**——适合"选品调研报告"、"Temu 扣款分析"等单次交付型服务，用"付费内容"形式卖；
  - ⚠️ 动态打赏不适合正经服务售卖（金额随意、无交付承诺）。

### 2. 抽成比例（已核实，与创始人掌握的 94% 一致）
- 创作者到手 = 粉丝付费的 **94%**
- 平台抽走 6% = **1% 支付手续费 + 5% 平台服务费**（官方口径，多来源一致）
- 无额外提现手续费（提现环节不重复抽成）

### 3. 提现方式
- 支持 **支付宝 / 微信 / 银行卡** 提现（绑定后申请）
- 需要满足最低提现金额（官方通常为几十元级，以后台显示为准；到账周期一般 3-7 个工作日，以申请时页面提示为准）
- 提现需**实名认证**（身份证 + 本人收款账户，姓名须一致）

### 4. 资质/实名要求
- 注册普通账号即可，在个人中心点"**成为创作者**"→ 填写创作信息 + 设置赞助方案 → 审核通过即成为创作者
- **实名认证是硬性要求**（收款/提现前提），需身份证认证 + 绑定本人支付宝/微信/银行卡
- 个体户/企业资质**不是必需**（个人创作者即可，平台定位就是个人创作者）

### 5. 卖 AI/虚拟服务合规性（平台规则角度）
- 平台官方推荐创作者类型明确包含"**软件开发者、教程课程作者、游戏开发者、独立开发者**"等（官网英文页甚至直接推荐 Technology/MOD 类目，首页已有"AI 人生重开手帐"这类 AI 相关创作者在售）
- **虚拟服务/数字内容售卖是平台主流形态**（付费内容、会员奖励多为虚拟交付），不存在类目禁止
- 平台规则红线主要是：**内容合法、不涉黄赌毒、不侵权、不虚假宣传、交付承诺需兑现**——AI 服务属于"技术服务/内容服务"，合规性风险低
- ⚠️ 注意：平台是"赞助/内容"框架而非标准电商交易框架，**无担保交易、无纠纷仲裁机制**，交付纠纷靠创作者自觉 + 平台冻结/封号约束——定价和交付承诺必须写清楚

### 6. 首次上架 → 开始赚钱的最小路径
1. 登录 → 实名认证（身份证 + 收款账户）
2. 成为创作者（填创作信息）
3. 建 3-5 个会员档位（低价引流档 19.9 → 中档 99 → 高价 499）
4. 发 3-5 条介绍动态/付费内容（展示案例、交付物示例）
5. 官网 sellerai.listaikit.com 挂上爱发电主页链接引流（闲鱼、朋友圈、私域同步导流）
6. 首单 ≈ 档位定价，到账 94%

## 四、风险提示

1. **平台规则/合规**
   - 虚拟服务可卖，但需**如实描述交付物**，避免"AI 生成"被买家误解为人工原创的纠纷；建议交付说明中明确"AI 辅助生成，可人工修改"。
   - 不涉黄赌毒、不代写学术论文/考试作弊类（简历/文案/PPT 正常商业服务无此风险）。
   - 平台以"赞助"名义收钱，**无担保交易/仲裁机制**——大额服务（选品调研 499、爬虫 200+）建议先收定金、明确交付节点，或引流到官网走正规合同/对公（大客户）。
2. **封号风险**
   - 频繁站外引流（微信号、二维码）可能被判违规，先做主页+动态展示，私信再给联系方式。
   - 批量注册、刷单、诱导退款会封号——只运营创始人这一个号。
   - 交付不兑现被大量投诉 → 冻结收益/封号。
3. **平台局限性**
   - 爱发电是**粉丝向订阅平台**，没有电商平台的搜索流量/类目曝光；买 AI 服务的电商卖家客户**不会主动来搜**——本质是"收款工具+内容展示页"，**流量必须自己带**（官网/闲鱼/私域导流）。
   - 月赞助自动续费与否取决于平台设置，需在档位说明写清楚。
4. **技术/访问**
   - 本机 afdian.net DNS 解析失败（ENOTFOUND），afdian.com 可访问；浏览器导航被 SSRF 策略拦截（需 IP 字面量）。后台操作建议：创始人直接在自己设备登录，或后续配置代理/白名单后由 Agent 浏览器自动化辅助。
5. **隐私/安全**
   - 不涉及 DEEPSEEK_API_KEY、不注册新账号、不付费——本方案仅信息调研，未做任何写操作。

## 五、结论摘要

- **能不能赚钱**：能。94% 到手比例在同类平台中最高（Patreon 5%服务费+支付费 ≈ 90-93%），虚拟服务是平台主流形态，合规可行。
- **怎么切入**：3 档订阅（19.9/99/299+）+ 单次付费服务（简历 49、Listing 99、Temu 199、选品 499 等），主页展示交付案例，官网+闲鱼+私域导流，爱发电当"收款+内容沉淀"端。
- **需要创始人配合**：① 自己设备登录 afdian（或配代理后 Agent 代操作）；② 实名认证 + 绑定支付宝/微信收款账户；③ 后台创建档位与发布内容（无 API，需人工/浏览器自动化）。
