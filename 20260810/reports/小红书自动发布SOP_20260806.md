## 🎯 核心结论（踩坑 20+ 轮总结）

1. **发布按钮是 `<xhs-publish-btn>` Vue 自定义组件**，不在 shadow DOM，按钮状态通过 host 属性暴露。触发方式：**JS dispatchEvent `publish` 自定义事件**，不要用坐标点击/文字搜索。
2. **隐藏杀手：标题字数超限**。小红书标题上限 **20 字**，超过时 `submit-disabled` 校验阻止提交，dispatch 无效且无报错提示。**必须 ≤20 字**（中英文混合按字符计，实测 22 字被拒、17 字通过）。
3. **定时开关**：`.post-time-wrapper .d-switch`。若之前误开（按钮显示「定时发布」），先点击关闭，按钮恢复「发布」。
4. **成功判定**：toast 捕获「发布成功」+ URL 跳离 `/publish/publish` → `/publish/success` → 自动返回 `?published=true`。三选一即可。

### 步骤

```python
# 1. 定位标签页
target = [t for t in ctx.pages if "creator.xiaohongshu.com" in t.url and "publish" in t.url][0]

# 2. 切「上传图文」tab（JS 叶子节点文本点击）
# 3. 上传配图：page.locator('input[type="file"]').first.set_input_files(IMG)
#    等待 .img-preview-area .pr 计数出现（30s 超时）
# 4. 填标题：page.locator('div.d-input input').first.fill(TITLE)
#    ⚠️ TITLE 长度必须 ≤20 字符！
# 5. 填正文：JS 枚举 div.ql-editor / .ProseMirror / [contenteditable="true"]
#    （选 w>200 h>50 的），mouse.click 后 keyboard.insert_text(BODY)
#    正文 ≤1000 字，末尾加话题：#话题1 #话题2
# 6. 关闭弹窗：Esc + 点空白 (400,200)
# 7. 注入 3 层响应捕获（fetch hook + XHR hook + MutationObserver toast 观察器）
#    捕获 window.__xhsPublishResult
# 8. 触发发布（核心！）：
#    const h = document.querySelector('xhs-publish-btn[is-publish="true"]');
#    if (h.getAttribute('submit-disabled') === 'true') → 校验没过，自查表单
#    h.dispatchEvent(new CustomEvent('publish', {bubbles:true, cancelable:true}));
# 9. 轮询 25s：window.__xhsPublishResult 或 URL 跳离 /publish/publish
```

### 成功判定优先级
1. URL 不含 `/publish/publish`（跳转到 `/publish/success`）→ 成功
2. 捕获结果 source=toast 含「发布成功」→ 成功
3. 捕获结果 body 含 `note_id` 或 `code==0` → 成功

### 风控识别（立即停手）
- 捕获 body 含 `-913x` / 「禁止发笔记」/「违反」/「违规」/「账号异常」→ 风控
- 频率控制：≤50 篇/天，避免短时间大量操作
- 建议用测试小号先验证

## 🔧 常见问题速查

| 现象 | 原因 | 解决 |
|------|------|------|
| dispatch 后无反应 | 标题超 20 字 / submit-disabled | 缩短标题，检查属性 |
| 按钮显示「定时发布」 | 定时开关被误开 | 点击 `.post-time-wrapper .d-switch` 关闭 |
| dispatch 后页面跳转内容丢失 | 定时模式下提交（v18 教训） | 先关定时开关再 dispatch |
| 找不到 xhs-publish-btn | 页面在视频/长文 tab | 先切「上传图文」 |
| #话题弹出联想 | 输入 # 触发话题联想 | Esc 或点空白关闭后发布 |
| 页面固定高度无法滚动 | SPA 特性 | 对 `.publish-page` 容器 scrollTop=scrollHeight |
