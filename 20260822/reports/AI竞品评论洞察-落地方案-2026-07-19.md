> **ReviewAI — 跨境电商卖家的AI竞品评论分析台，输入ASIN即刻获得产品改进方向。**

### 3.3 数据采集方案

#### 方案A：自建Amazon爬虫（推荐MVP使用）

**技术栈**：
- 语言：Python (Scrapy + Playwright) 或 Node.js (Puppeteer/Playwright)
- 代理：BrightData/ProxyCrawl/Smartproxy（住宅IP代理池）
- 速率：每个ASIN约50-300条评论，控制在1-2请求/秒

**反爬策略**：
| 挑战 | 应对方案 |
|------|---------|
| IP封禁 | 住宅IP代理池（50+ IP轮换） |
| CAPTCHA | 打码服务（2Captcha/Capsolver） |
| User-Agent检测 | 随机UA + 浏览器指纹模拟 |
| 请求频率限制 | 速率控制 + 随机延迟(1-5s) |
| 页面结构变化 | HTML解析 + JSON端点优先 |
| Cookie/Session | 维护登录态池（可选） |

**评论获取方式优先级**：
1. **JSON端点**：`https://www.amazon.com/hz/reviews-render/ajax/reviews/get/...`（结构化数据，解析稳定）
2. **Product Advertising API**：官方接口，但需审核且限额
3. **HTML解析**：fallback方案

**成本估算**（每月10,000 ASIN分析，每ASIN 50条评论）：
- 代理费用：$50-100/月（Smartproxy住宅代理）
- Workers计算：$5-10/月（Cloudflare Workers）
- 总采集成本：~$100/月

#### 方案B：第三方API（推荐Beta/MVP初期混合使用）

| API | 价格 | 评论覆盖 | 稳定性 | 延迟 |
|-----|:----:|:--------:|:------:|:----:|
| **Keepa API** | €19-€149/月 | 价格数据为主，评论有限 | ⭐⭐⭐⭐ | 低 |
| **Rainforest API** | 约$0.02/请求 | Amazon全数据 | ⭐⭐⭐⭐ | 中 |
| **ScrapingBee** | $49-$299/月 | 通用爬虫 | ⭐⭐⭐ | 高 |
| **Canopy API** | 免费100次起 | Amazon产品+评论 | ⭐⭐⭐⭐ | 低 |
| **Easyparser** | 免费/按量 | Amazon评论 | ⭐⭐⭐ | 中 |

**推荐**：MVP初期用自建爬虫（控制成本），遇到反爬瓶颈时切到Canopy API或Rainforest API作为备用。

**Amazon反爬风险评估**：
- 2025年起Amazon加强了对评论页面的反爬，部分版面需要登录才能查看全部评论
- 应对方案：维护一个低优先级的Amazon买家账号池（5-10个账号），带Cookie爬取
- 极端情况：Amazon在2026年可能进一步收缩评论公开访问——届时必须依赖第三方API

#### TikTok Shop评论方案（Post-MVP）

- TikTok Shop开放了部分商品评论API
- 可通过Web端爬取（TikTok反爬更严，需特殊代理）

### 3.4 AI 分析 Pipeline

```
原始评论
   │
   ▼
┌─────────────┐
│  Step 1:    │  清洗 & 格式化
│  评论清洗    │  → 去重、去机器评论
└─────────────┘  → 语言检测（中/英/其他）
   │              → 翻译非英文评论（如需）
   ▼
┌─────────────┐
│  Step 2:    │  情感打分（1-5星转化情绪分）
│  情感分析    │  → 正面/中性/负面分类
└─────────────┘  → 极端情感标记
   │
   ▼
┌─────────────┐
│  Step 3:    │  → K-Means/BERTopic 聚类
│  语义聚类    │  → 差评主题聚类（质量/尺寸/物流/客服）
└─────────────┘  → 好评主题聚类
   │              → 每个聚类记录出现频率
   ▼
┌─────────────┐
│  Step 4:    │  → 消费者画像推断
│  关键发现    │  → Top 5好评原因 + 出现率%
└─────────────┘  → Top 5差评原因 + 出现率%
   │              → 未满足需求分析
   ▼
┌─────────────┐
│  Step 5:    │  基于提示词工程
│  建议生成    │  → 每条建议带"为什么"+"怎么做"
└─────────────┘  → 优先级排序（影响面×修复难度）
   │
   ▼
   输出结构化JSON → 前端渲染
```

1. **成本碾压**：DeepSeek V4 Pro 输出 ¥6/百万tokens ≈ $0.83/百万tokens，仅为 Claude Sonnet 4 ($15) 的 1/18
2. **中文能力**：DeepSeek 母语级中文，处理亚马逊中国卖家的中英文混合评论更佳

4. **已永久降价**：2026年5月确认 V4 Pro 永久降价至原价1/4

**成本测算**（单次分析）：
- 每ASIN约50-200条评论分析
- 按100条评论计算，Prompt约3,000 tokens（评论内容2,500 + 指令500）
- 输出约500 tokens
- DeepSeek V4 Flash成本 = (3,000×¥0.025 + 500×¥6) / 1,000,000 = ¥0.003075
- ≈ **$0.00042/次分析**（几乎可以忽略不计）

**关键**：成本极低，$1可以分析约2,400个ASIN！
