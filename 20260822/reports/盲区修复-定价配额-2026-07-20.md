## 修复的三个盲区

### 1. Pick 定价自相矛盾
- **问题**: 子Agent 擅自定价 $49/mo，与全局 $19.90/$29.90/$199 不一致
- **修复**: 三档 → Free $0(3天/5次) / Starter $19(30次/月, 10次/天) / Pro $29(100次/月, 20次/天)
- **页面**: pick.listaikit.com Pricing 区块 + fair-use 透明声明

### 2. Pick API 日配额无限
- **问题**: 付费用户 9999/天，单用户可无限烧 API
- **修复**: 日上限 → 5(试用) / 20(付费)，超限返回 429
- **文件**: `app/api/pick/analyze/route.ts`

### 3. ReviewIQ Pro 无限配额
- **问题**: `PLAN_LIMITS.pro = -1`(无限)，100品日刷新 → $6.25/月 API 成本
- **修复**: Pro 改为 100/月（约 $0.71 API 成本），trial 改为 999
- **文件**: `lib/quota/engine.ts`
