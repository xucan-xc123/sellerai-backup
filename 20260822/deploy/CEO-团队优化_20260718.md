# CEO 团队优化方案

**时间：** 2026-07-18 21:45
**背景：** 创始人反映"太累了"，根源是参谋长（我）调度方式低效——知乎发文一次任务派 4 个 agent，累计烧 82 分钟 token 零产出，主对话框被锁半小时。

## 核心诊断
- 死不认栽：Edge 有头模式第一次崩溃就连试 4 次
- 回报虚数：agent 说"正文已写入"我就信了，实际只写了 89 字
- 撒网不控：同一件事派 4 个并行 agent，4 倍 token 烧同一个不可能的事
- 主城被占：主对话框被一个任务锁了半小时
- 不做预检：派 agent 前没确认环境是否可行

## 新规则（已写入 MEMORY.md 和 ops/team-rules.md）
1. 一事一 agent，失败不重试
2. Step 0 预检机制（先确认能跑再派人）
3. 主对话框零阻塞（派完即释放）
4. 回报可验证（不发虚数）
5. 默认禁用 --headed（Edge 有头必崩）
6. 并发 ≤2
7. 失败 10 秒速报
