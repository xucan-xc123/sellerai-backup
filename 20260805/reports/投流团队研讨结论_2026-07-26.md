## 一、四方案逐项评估

### 方案A：Reddit Ads — ¥150/7天 ❌ 当前不可行

| 维度 | 评估 |
|---|---|
| **可行性** | **不可行。** 国内家用宽带 + 养号中未发帖 + 需绑境外卡，三重堵点。Reddit 对新号跑广告审核极严，账户无发帖历史会被拒审或风控封号。|
| **支付** | Reddit Ads 要求绑定国际信用卡或 PayPal 美元账户。国内双币信用卡 (Visa/Mastercard) 理论上可绑，但在国内 IP 环境下通过率低；即使绑上，¥150≈$20.6，扣款时还有跨境手续费和汇率损失。 |
| **预计点击** | $20.6 ÷ $0.50~1.20 CPC = **17~41 次点击**，远低于原预估的 40~80 次。 |
| **预计转化** | 按 Amazon 卖家工具类 3~8% CVR 估算 = **0.5~3 个注册/试用**。 |
| **隐性成本** | 账号若被封（新号广告是高危行为），之前的养号投入全白费。后续补号成本极高。 |
| **风险** | 🔴 **高风险。** 支付无法保证成功 -> 账号封禁风险 -> 即使支付成功，账户活跃度不足也会被限流。 |

| **隐性成本** | 开户时间 2~3 工作日 + 公众号认证费 ¥300/年 + 对公账户成本。¥200 预算无法覆盖任何一项。 |

### 方案C：百度竞价SEM — ¥200 ❌ 不可行

| 维度 | 评估 |

| **预计转化** | 假设 10~20% CVR（搜索直达型工具） = **4~20 个注册/试用**。数量级最优。 |
| **隐性成本** | 开户后需持续优化关键词、质量度、落地页。竞价账户托管需要时间和技能。 |

## 四、具体执行步骤（前3步）

### 第1步：筛选 10 位跨境小博主（Day 1~3）

在小红书、抖音、B站搜索以下关键词，列出活跃博主名单：
- 「亚马逊新手 选品」「跨境电商工具」「亚马逊关键词教程」
- 筛选标准：粉丝 500~5000、近30天有更新、内容与跨境相关
- 用表格记录：平台 / 账号名 / 粉丝数 / 联系方式 / 内容风格

评分说：**直接在小红书和抖音搜"亚马逊 工具"可以看到很多博主**

**¥200 用法：** 筛选出第一批6位符合要求的博主。

### 第2步：触达 + 送 Pro 版（Day 3~7）

模板化私信内容：
> 「您好，我们是 SellerAI（卖家选品分析工具）/ KeyWordIQ（关键词研究工具），看到您分享的跨境电商内容很棒。我们正在找真实用户做产品体验，可以免费送您 Pro 版（价值XXX/年），只需要您真实体验后在任何平台分享反馈即可，没有硬性要求，不好的地方也欢迎提建议 :)」

**¥200 用法：** 对其中3~4位配合度高的博主，发出 ¥30~50 微信红包作为"感谢费"/配合激励。

### 第3步：提供 Brief 素材并等待内容产出（Day 7~21）

为博主提供：
- 简单的 3~5 个使用场景建议（不是脚本，是建议方向）
- 产品截图包 + Logo 素材
- 专属邀请链接 / 优惠码（方便追踪效果）
- **关键：** 不强求脚本，真实体验内容才有效

**¥200 用法：** 若几位博主都产出了质量不错的内容，剩余的 ¥100 可作为第一批投放的"内容加热"费用（抖音 DOU+ ¥50/条 或 小红书薯条 ¥50/条）。
