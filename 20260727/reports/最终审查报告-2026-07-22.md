## 四、剩余风险（按严重性）

### 🔴 P0 — 阻塞真实用户

1. **注册链路 502**
   - `POST /api/auth/send-code` 返回 `502 Bad Gateway`
   - 直接调用 Resend API 是通的，说明 Cloudflare Worker  outbound fetch 到 Resend 失败
   - **影响**: 新用户无法注册/登录，整个付费转化链断裂
   - **建议**:
     - 检查 Cloudflare Worker 是否被墙/是否需要代理
     - 或改用 Resend 的 SMTP 接口（`smtp.resend.com`）绕过 HTTP fetch
     - 或先关闭强制登录，恢复匿名配额模式应急

2. **Pricing 按钮链接混乱**
   - Listing / Max / Annual 的 Subscribe 指向 `/app`（前端登录检查）
   - Pro 的 Subscribe 指向旧 Gumroad `https://xucan.gumroad.com/l/kajyx`（Legacy 全权限商品）
   - **影响**: 用户点击后权限与预期不符；新商品未接入
   - **建议**: 新建三个 Gumroad 商品并更新按钮 href

3. **缺少独立 `/pricing` 页面**
   - `/pricing` 404
   - **影响**: 从外部引流到定价页会直接碰壁
   - **建议**: 添加 `/pricing` 路由或 301 到首页 `#pricing`

### 🟡 P1 — 影响体验

4. **F3 未处理**: API Key/JWT Secret 仍在 `wrangler.jsonc` 明文 `vars` 中
5. **未验证登录后配额扣减**: 因注册阻塞，无法 E2E 验证
6. **ReviewIQ 配额 reset_at 初始值**: 新用户注册时可能未正确写入，导致首次不重置
