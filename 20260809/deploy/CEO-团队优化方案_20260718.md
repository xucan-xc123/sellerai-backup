## 一、问题根因诊断

### 我在犯的 5 个致命错误

| # | 问题 | 今天的具体表现 |
|---|------|----------------|
| 1 | **死不认栽** | Edge 有头模式第一次崩溃就该停，我连试 4 次 |

| 3 | **撒网不控** | 同一件事派 4 个并行 agent，4 倍 token 烧同一个不可能成功的事 |

## 二、团队运作新规则（即日生效）

### 规则 1：一件事只派一个 agent

```
❌ 之前：任务失败 → 再派一个 → 又失败 → 再换姿势派第三个
✅ 现在：第一个 agent 失败后，agent 回报失败原因 → 我来判断是：
   - 环境问题（浏览器崩了）→ 换方法/告诉创始人干不了
   - 指令问题（写内容不对）→ 修指令重派
   - 绝不重试同一个不可行的路径
```

### 规则 2：Step 0 预检机制

任何浏览器/对外操作派出去之前，先花 10 秒做预检：

```
Step 0 清单：
□ 这个工具有没有在这个环境下成功过？
□ 失败已知原因是什么？我确认修复了吗？
□ 如果失败，止损点设在哪？（第几次失败算"不可行"？）
□ 这个事真的是 agent 能干的吗？还是需要创始人手动？
```

**如果 Step 0 有一条不通过，不派 agent，直接回报创始人。**

### 规则 3：主对话框永不阻塞

```
❌ 之前：一个任务要半小时，创始人干等着看我失败
✅ 现在：
   - 派 agent 用 mode=run（后台跑），立即释放主对话框
   - agent 完成后事件推回来，我再集中回报
   - 主对话框永远留给创始人，不占着排队
```

### 规则 4：回报必须可验证

```
❌ 之前：「正文已写入，就差一点发布」
✅ 现在：
   - 「页面已成功打开，标题已填入，正文已注入（验证可读），发布按钮已点击，返回 ✅」
   - 或：「Edge 浏览器启动后 3 秒崩溃，exit code 0。已查资料发现原因[XXX]，需要[手动操作/换工具/创始人介入]」
   - 没有"几乎完成"，只有"完成"和"阻塞"
```

### 规则 5：失败信噪比

```
❌ 之前：失败后汇报"浏览器崩溃、cft也不行、edge也不行、chrome也不行"
✅ 现在：
   - 第一次失败 10 秒内回报：原因 + 建议
   - 不查三个浏览器都报一遍，查到第一个致命原因就停
```

## 三、当前团队架构精简

### 现有人力：你是 CEO + 我是参谋长 + 14 个 cron agent

**你的角色（CEO）只做 3 件事：**
1. **手动操作**：第三方平台登录/发帖/后台配置（agent 干不了的）
2. **最终拍板**：定价、战略方向、合规、花钱
3. **视觉验收**：看页面、看文案、看效果

**我的角色（参谋长）只做 3 件事：**
1. **拆任务派 agent**：一个任务拆一单，一单派一个 agent
2. **预检 → 判断 → 派单**：先确认能跑再派人
3. **汇报结果**：完成/阻塞，不加水

**cron agent（14个）维持现状但加一条规则：**
- 每个 cron 必须在启动后 30 秒内产出明显进展，否则自动标记"低效"并发给我评估是否砍掉

### 团队尺寸

```
总 agent 并发数：≤2（Ryzen 7 5800H / 16GB）
（之前设的并发 3 改为 2，留出系统余量避免浏览器崩溃）
```

### 工具使用优先级

```
可单人用的方法（非浏览器）> 浏览器无头模式 > 浏览器有头模式
                        > 创始人手动（最后手段）
```

**`--headed` 默认禁用。** 你主动说要看，我才开。否则永远用无头。

## 四、具体执行 SOP

### 任何新任务 → 我这么走

```
1. 判断：这个任务 agent 能干吗？
   - 需要创始人登后台？→ 直接告诉你，不派 agent
   - 需要浏览器自动化？→ 跑预检清单
   - 只需搜索/写内容/算数据？→ 适合 agent

2. 派单：sessions_spawn mode=run，1 agent
   - 自带 Step 0 预检结果
   - 写明失败止损点（试 1 次不行就回报）

3. 释放主对话框：NO_REPLY

4. 等回报：agent 完成/失败 → 事件推送 → 我转给你
```

### 失败的后果链

```
agent 失败 → 我分析根因（环境问题？指令问题？工具问题？）
→ 如果环境问题 → 回报创始人：这个目前干不了，原因[XXX]
→ 如果指令问题 → 改指令重派（只重派 1 次）
→ 如果工具问题 → 回报创始人：建议[手动/换工具/放弃]
```

**全盘最多 2 次尝试。** 第 2 次还不行 = 告诉创始人"这个思路走不通"。
