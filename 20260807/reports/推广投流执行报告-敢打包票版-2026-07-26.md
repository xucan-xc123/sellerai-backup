## 二、渠道实战方案（按效果确定性排序）

### 🥇 Tier 1：必做，0成本，确定性最高

#### 1. Gumroad Discover 站内搜索 — 零成本，马上见效

Gumroad 平台日活用户本身就倾向于购买数字产品/SaaS。你的产品已经上架了，但 Gumroad 搜索排名靠的是**销量 + 描述匹配度 + Tags**。

**今日可执行：**
- [ ] 检查两个产品的 Tags：在 Gumroad 编辑页面 → Tags 字段 → 必须填入 `amazon seller`, `keyword research`, `amazon fba`, `ecommerce tools`, `ai saas`
- [ ] 检查 Description 是否包含高频搜索词（如 "amazon listing generator free", "amazon keyword tool"）
- [ ] 确保 **"Discoverable" 开关打开**

**预期效果**: Gumroad 会把你推荐给已经在搜类似工具的用户。保守估计每天 3-10 次自然浏览，转化率 2-5%。

> ⚡ **这个渠道0成本，15分钟就能做完。不做白不做。**

#### 2. 亚马逊卖家论坛/社群免费发帖 — 直接触达目标用户

Amazon Seller Central 论坛、Reddit 的 r/FBA、r/AmazonSeller（养号中）、Facebook 亚马逊卖家群组——这些地方每天都有卖家在问"有没有好用的工具"。

**操作方式：**
- 找到帖子"How do you do keyword research?" → 回复详细方法 → 最后自然提到"我用的是 KeyWordIQ，keywords.listaikit.com 可以免费试用"
- **不是硬广**——先提供价值再带链接，社区规则允许

**预期效果**: 每个高质量回复 ≈ 10-50 次精准点击。每天花 30 分钟回复 3-5 个帖子，每周至少 2-3 个免费试用注册。

> ⚡ **零成本，只需要时间。但前提：Reddit 养好号（7天+），或先用微信/Telegram 卖家群。**

### 🥈 Tier 2：小成本测试，¥200-500/月，确定性中等

#### 3. Reddit Ads — ¥200/月，最便宜的精准流量

**为什么选它而不是 Google Ads：**
- CPC $0.50-1.20，是 Google 的 1/3
- 定向精准（r/FulfillmentByAmazon 有 40 万+ Amazon 卖家）
- 最低日预算 $2（≈¥15）即可开始

**具体配置（照抄）：**

| 设置项 | 值 |
|--------|-----|
| 目标社区 | r/FulfillmentByAmazon, r/AmazonSeller |
| 日预算 | $3（≈¥22） |
| 广告文案 | "90% of Amazon sellers waste money on bad keywords. Here's the fix. → [链接]" |
| 目标网址 | keywords.listaikit.com（KeyWordIQ 首页，免费试用入口） |
| 投放时长 | 先跑 7 天看数据，效果好立即加码 |
| 月总预算 | ~¥200（≈$28） |

**预期产出（保守）：**
- 7 天 ≈ 40-80 次点击
- 转化率 2-5% → 1-4 次免费试用
- 试用→付费 10% → **7-14 天内有 0-1 个付费用户**

**判定标准（严格执行）：**
- CPC > $1.50 → 暂停素材，换文案再试
- 点击 > 50 但 0 试用 → 砍掉这个渠道
- CPC ≤ $1.00 且有试用 → **立即加码到 ¥500/月**

#### 4. 微影响者合作（Micro-influencer）— ¥500/次，确定性高

Amazon 卖家圈子里有很多小型 YouTuber/KOL，粉丝 1,000-5,000，但信任度极高。一个真实推荐 ≈ 几十个精准用户。

**操作方式：**
1. 在 YouTube 搜 "amazon fba tools review" "best amazon seller software 2026"
2. 找到粉丝 500-5,000 的中文/英文 Amazon 卖家内容创作者
3. 私信："我有一个 AI 工具，可以免费给你用 Pro 版，如果你觉得好用可以做个测评吗？"
4. 如果他们愿意收钱做推广，给 $50-100（≈¥350-700）

**为什么不谈直接给钱？** 给免费 Pro 版让他们先用——好用他们自然会推荐。不花钱就能拿到第一个测评。

**预期效果**: 1 个测评视频 ≈ 100-500 次精准访问 → 5-25 次试用 → 0-2 个付费用户。

**判定标准：**
- 发 10 条私信，有 2-3 个回复就算成功
- 其中 1 个愿意帮忙 → 零成本获得一次产品曝光

> ⚡ **这条路的ROI可能是所有付费渠道里最高的。因为 Amazon 卖家极度信任同行的真实测评。**

- ✅ 月预算 ≥ ¥1,000（¥33/天，足够每天 10-20 次点击）

**在此之前：不要碰。**

## 六、如果这个方案不奏效怎么办？

如果严格按照以上方案执行 60 天，仍然 0 付费用户——**问题不在推广，在产品本身**。

到时候必须回答 3 个问题：
1. **试用用户为什么没付费？**（价格太贵？功能不够？竞品更好？）
2. **试用用户注册后发生了什么？**（他们用了吗？用得爽吗？）
3. **有试用用户在跑吗？**（如果没有——推广的根本没触及Amazon卖家。渠道选错了。）

**解决方案不是加预算，是先修产品 + 找 3-5 个真实卖家聊一聊。**
