## 6. 新项目评估与落地路径

### 6.1 项目一：跨境电商 AI 商品视频生成（VideoGen for Sellers）

| 维度 | 评审结论 |
|------|----------|
| 方向价值 | ✅ 与 V1 天然延伸（Listing → 视频），技术复用度高（脚本/数据层） |
| 技术可行性 | ⚠️ 脚本/数据层 ✅（DeepSeek 即可）；**视频实际生成依赖外部付费 API（Sora/Runway/Pika），DeepSeek 不出视频** |
| 现金流 | 🔴 阻塞级：视频 API 是主成本，当前 ¥22.50 余额完全覆盖不了 |
| 护城河 | ⚠️ 偏弱（wrapper 形态），靠 Listing 联动 + 多语种模板库 + 用户素材沉淀积累 |
| **评审结论** | **谨慎（条件可行）— 先做轻量验证 MVP，注资后再扩｜第一优先** |

**Phase 0 — 人工替身验证（0 现金，仅耗 DeepSeek 余额）**
- 范围：DeepSeek 生成多语种脚本 + 人工/设计拼装 5–10 条样片 + 找 3–5 个 V1 老用户测付费意愿
- 工期：1–2 周｜资源：1 全栈 + 1 设计（兼职）+ PM

**Phase 1 — 自动生成 MVP（需注资 ¥3.5K–7K 视频 API 测试金）**
- 范围：接入单一视频 API（建议 Runway/Pika）+ Next.js UI + 异步渲染队列 + 复用 V1 数据提取
- 工期：6–8 周（非调研报告所称 4–6 周）｜外部 API 预算 $500–1000（≈¥3.5K–7K）

### 6.2 项目二：海外 GEO / AI 搜索优化 SaaS（AISEO for Export）

| 维度 | 评审结论 |
|------|----------|
| 方向价值 | ✅ 蓝海真实，窗口期 6–12 个月，差异化强 |
| 技术可行性 | ⚠️ 内容优化层 ✅（DeepSeek）；**多平台监测（ChatGPT/Gemini/Claude 排名）须付费官方 API 或爬取（ToS 违规风险），净新增 + 合规不确定** |
| 现金流 | 🔴 阻塞级：监测须开 OpenAI/Google/Anthropic 付费账号，远超当前现金 |
| 客群偏离 | ⚠️ B2B 外贸 vs V1 的 Amazon 卖家，获客渠道/话术需重建，分散度高 |
| **评审结论** | **暂缓（先试点）— 人工案例验证需求，暂不投入工程重 build｜第二优先（串行）** |

**Phase 0 — 人工 GEO 审计试点（0–低现金）**
- 范围：DeepSeek 生成优化内容 + 人工向 AI 平台查询并记录排名 + 为 3–5 个 B2B 客户做付费试点报告
- 工期：2–3 周｜资源：1 GEO/SEO 专员 + 1 全栈 + 主理人获客

**Phase 1 — 监测+报告 SaaS（需注资 ¥3.5K–11K 监测 API 金）**
- 范围：官方 API 监测（规避爬取合规风险）+ Next.js 仪表盘 + DeepSeek 内容优化 + 轻量结构化知识库
- 工期：8–10 周｜监测 API 预算 $500–1500（≈¥3.5K–11K）

### 6.3 团队建议节奏

> **两项目当前都不可直接烧钱开工**（现金 ¥22.50 vs 所需 ¥1.4万–5.6万）。正确策略：**零/低成本验证先行 → 用户注资 → 工程化 MVP**。

1. 立即放行两个 **Phase 0**（几乎零成本，仅耗 DeepSeek 余额，风险最低）。
2. **项目一优先**做自动生成验证（协同强、验证快）；**项目二串行**跟进（先做人工案例）。
3. Phase 0 拿到「付费意愿 / 效果可感知」证据后，再就 Phase 1 注资拍板。
