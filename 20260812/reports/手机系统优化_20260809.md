# 手机系统优化报告（华为 JER-AN20 / Android 12）

**日期**: 2026-08-09 21:31-21:45
**设备**: 华为 JER-AN20 (TNL0221105013306), Android 12, 8GB RAM, 128GB 存储
**用户诉求**: 玩王者荣耀卡顿，需要系统优化

## 诊断结果（优化前）

| 指标 | 优化前 | 健康值 | 判定 |
|------|--------|--------|------|
| 可用内存 | 1.7GB / 8GB (21%) | >3GB | ⚠️ 严重不足 |
| Swap 占用 | 3.4GB / 4GB (85%) | <50% | ⚠️ 疯狂换页（卡顿主因）|
| 存储占用 | 83GB / 109GB (77%) | <80% | ⚠️ 偏满 |
| 电池温度 | 38°C | <40°C | ✅ 正常 |

## 根因分析

1. **微信后台进程集群 ≈1.4GB**：主进程 563MB + 小程序 appbrand0 454MB + appbrand1 300MB + push 101MB
2. **闲鱼多开进程 ≈740MB**：主进程 + channel + windowChannel + gpu_process + render_proc0（5 个进程）
3. **抖音 520MB**（CPU 10.6%）、**快手** 后台狂耗电（wifi 266-711mAh）
4. **王者荣耀后台挂机 528MB**：玩完未退干净
5. **美团 PinProcess 139MB**、华为智能助手全家桶 ~450MB

→ 8GB 内存被榨干，Swap 85% 打满 → 系统持续读写交换分区 → 卡顿/发热/掉帧

## 已执行优化

### 1. 缓存清理
- `pm trim-caches 0` 系统级清理全部应用缓存（多次执行）
- 王者荣耀缓存清理

### 2. 进程清理（force-stop）
- 抖音、闲鱼、美团、王者荣耀、快手、小艺助手、华为智能、应用市场、快应用、华为建议
- 微信子进程（appbrand0/1、xweb、push）反复 kill

### 3. 后台运行限制（appops，治本防自启）
```

com.smile.gifmaker          RUN_IN_BACKGROUND deny  ✅
```

- 后台进程上限 = 4（`background_process_limit`）
- 动画缩放 1.0x → **0.5x**（window/transition/animator，减少渲染负担）

## 王者荣耀专项建议（给用户）

1. **进游戏前先手动清理后台**：下拉任务栏 → 一键清理（或长按最近任务 → 全清）
2. **游戏内设置**：帧率选"高"（60fps），画质选"高清"或"均衡"；8GB 内存机型不建议开"极致画质+极高帧率"
3. **打开华为游戏助手**：游戏启动时从游戏空间进入，可开 GPU Turbo + 免打扰
4. **充电时玩会发热降频**：建议电量 >50% 且拔掉充电器玩，或开空调/风扇散热
5. **每周清一次缓存**：设置 → 存储 → 清理，或让豆包定期帮你执行
6. **微信小程序用后退出**：appbrand 进程反复被拉起占内存

## 注意事项
- 抖音/快手/美团/闲鱼被限制后台运行后，**收不到消息推送**（需要用的时候打开 App 即可）
- 王者荣耀/和平精英被限制后台运行：不影响玩游戏，只影响"切后台挂机"
- 如需恢复某个 App 后台推送：`adb shell appops set <包名> RUN_IN_BACKGROUND allow`
