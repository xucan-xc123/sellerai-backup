# 产品上线强制检查清单（所有项目通用，缺一不可）

## ⚠️ 使用规则
1. 任何产品/功能/页面**上线前必须逐项打勾**，缺一个都不许部署
2. 每条检查项标注负责人 + 通过证据
3. 参谋长验收打最终 ✅ 才能部署
4. 创始人发现的问题 → 先查本清单哪条漏了 → 补上 → 全团队复训

---

## 第 0 关：需求评审（启动前）

- [ ] 竞品对标分析已产出（至少 3 个竞品的功能 + 价格 + 数据源对比表）
- [ ] 目标用户画像明确（谁会用、为什么选我们而不是竞品）
- [ ] 核心差异点至少 1 个（价格/功能/覆盖范围/数据质量，至少有一项领先）
- [ ] 定价已参照竞品基准线，有客观理由（不是拍脑袋）

## 第 1 关：支付链路（上线前一天）

- [ ] 所有购买按钮指向的链接，实际在浏览器中打开验证过
- [ ] Gumroad 产品价格与页面宣传价格完全一致（每档逐一核对）
- [ ] 免费版/试用版的跳转逻辑正确（不错误导向付费页）
- [ ] 优惠券/折扣码生效验证

## 第 2 关：功能完整性

- [ ] 核心功能端到端可用（用真实输入测试，不是 mock 数据）
- [ ] 所有输入框的边界情况验证（空输入、超长、非法字符）
- [ ] 错误提示用户友好且不泄露内部信息
- [ ] 配额/限流逻辑在多并发下验证
- [ ] CSV 导出等功能验证文件格式正确

## 第 3 关：数据质量

- [ ] 数据来源明确标注（真实数据 / API / AI 估算 / 第三方）
- [ ] AI 生成的估算数据有醒目的免责声明
- [ ] 如果接入真实 API，确认 API Key 有效、速率限制已处理
- [ ] 返回结果与竞品同关键词结果对比（≥5 个样本）

## 第 4 关：多语言 + 本地化

- [ ] 所有页面（含错误提示、按钮、定价卡）中英双语覆盖
- [ ] 语言切换不丢失当前状态
- [ ] 默认语言根据浏览器 Accept-Language 正确判断

## 第 5 关：部署 + 验证

- [ ] 构建成功（无报错）
- [ ] 部署后主页面 HTTP 200
- [ ] 所有 API 端点响应正常
- [ ] 自定义域名 + HTTPS 正常
- [ ] Cloudflare secrets 确认存在（不依赖 .env）

## 第 6 关：安全

- [ ] .env 文件不在代码仓中
- [ ] API Key 存在 Cloudflare secrets 而非明码
- [ ] CORS 白名单正确
- [ ] 输入无注入风险
- [ ] 错误信息不泄露内部路径/堆栈

## 第 7 关：SEO + 运维

- [ ] robots.txt 存在
- [ ] sitemap.xml 存在且域名正确
- [ ] meta title/description 完整
- [ ] 监控 cron 已更新（指向正确 URL，不监控旧 slug）
