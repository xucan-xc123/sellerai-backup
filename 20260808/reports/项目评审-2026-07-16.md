| **技术栈** | 项目1/2 均写"Python/FastAPI + 独立NLP/视频引擎" | SellerAI 实际栈 = **Next.js + DeepSeek + Vercel**；V1 已有商品数据提取、多语种文案、SEO 优化逻辑 | 报告高估了"直接复用 Python 管线"的可行性，低估了"在 Next.js/Vercel 上做视频/监测重任务"的架构改造成本 |

## 1. 项目一：跨境电商 AI 商品视频生成（VideoGen for Sellers）

### 1.1 技术可行性（对照 Next.js + DeepSeek + Vercel）

| 子模块 | 可行性 | 说明 |
|--------|--------|------|
| 多语种带货脚本生成 | ✅ 高 | 直接复用 V1 文案/卖点提取/品牌调性建模，DeepSeek 即可，成本极低 |
| 商品数据提取（Amazon/Shopify 链接） | ✅ 高 | V1 已有，直接复用 |
| **视频实际生成** | ⚠️ 中低 | **DeepSeek 不出视频**。必须新接 Sora/Runway/Pika 等外部付费 API，这是净新增集成 + 持续按量付费 |
| 多尺寸/多平台适配输出 | ⚠️ 中 | 模板化可解，但跨平台规格（TikTok 9:16 / Amazon 主图 1:1 等）需积累模板库 |
| 渲染/队列架构 | ⚠️ 中低 | Vercel serverless 有 60s–5min 超时且无 GPU，**不适合跑视频渲染**。需引入后台队列/Worker 或干脆把渲染交给外部 API 异步回调 |

**结论**：报告说"MVP 4–6 周、复用度9/10"只对**前半段（脚本+数据）**成立。真正的产品交付物（视频）依赖外部付费 API + 新架构，**实际净新增工作量约 40–50%**，真实 MVP 更接近 **6–8 周**（含一个视频 API 集成 + 异步架构）。

### 1.2 启动成本与现金流压力

- 当前 DeepSeek 余额 ¥22.50 → 仅够覆盖**脚本层**的模型调用（几百条脚本没问题）。
- 但**视频 API 是主成本**：调研报告估 $0.5–2/条，首月 API+服务器 $2K–5K。即便只做验证，想自动出 20–50 条样片也要 $50–200 外部 API 费，**当前余额完全覆盖不了**。
- **现金流压力：严重（阻塞级）**。在用户注资（哪怕一笔 ¥3K–5K 的视频 API 测试金）之前，只能做"人工替身式"验证，不能做自动生成。

### 1.3 竞争格局与护城河

- 报告判断"直接竞品少"基本成立：通用工具（Sora/Runway/Pika）不懂卖点、不产出多语种脚本、不联动 Listing。
- **但护城河偏弱**：本质是"DeepSeek 脚本 + 外部视频 API + 跨境模板"的组合，**进入门槛低**。风险在于上游（Sora/Runway）若降价或原生支持多语种/电商模板，wrapper 价值会被侵蚀。
- 相对稳固的护城河只能是：**Listing 数据联动 + 跨境多语种模板库 + 用户素材资产沉淀**。需靠时间积累，非技术壁垒。

### 1.4 与 SellerAI 主线协同 / 分散风险

- ✅ **协同极强**：V1 用户"做完 Listing → 做 Listing 视频"是天然刚需，可形成"文案→图片→视频"产品矩阵， upsell 路径短。
- ⚠️ 分散点：视频 infra（异步渲染/外部 API）是新工程域，会分散对 V1 深化的精力。

### 1.5 评审结论：**谨慎（条件可行）— 推荐先做轻量验证 MVP，注资后再扩**

理由：方向对、协同强、脚本层成本极低；但核心视频能力依赖外部付费 API 且当前现金枯竭，不能按原方案烧钱开工。正确节奏是**先用现有 DeepSeek 余额跑"人工替身"验证付费意愿**，再小规模注资做自动生成 MVP。

## 2. 项目二：海外 GEO / AI 搜索优化 SaaS（AISEO for Export）

### 2.1 技术可行性（对照 Next.js + DeepSeek + Vercel）

| 子模块 | 可行性 | 说明 |
|--------|--------|------|
| 内容优化引擎（GEO 内容生成） | ✅ 高 | 复用 V1 多语种内容 + 卖点提取 + SEO 逻辑，DeepSeek 即可 |
| 仪表盘前端 | ✅ 高 | 直接复用 Next.js |
| **多平台监测（ChatGPT/Gemini/Claude 排名）** | ⚠️ 中低 | **必须查询目标 AI 本身**才能测排名。要么官方 API（OpenAI/Google/Anthropic 付费账号，净新增成本），要么爬网页 UI（**ToS 违规风险 + 极不稳定**）。这是项目最硬的技术/合规骨头 |
| 知识图谱 | ⚠️ 中 | 净新增构建，MVP 可先用轻量结构化数据替代，不必一上来做重图谱 |
| 效果量化 | ⚠️ 中低 | "让 AI 优先推荐"难给出确定性保证，影响续费与口碑 |

**结论**：内容优化层可行且便宜；**监测层是净新增 + 有合规风险**，是工期与成本的主要不确定性来源。真实 MVP（监测+基础报告）≈ **8–10 周**，而非报告说的 6–8 周。

### 2.2 启动成本与现金流压力

- DeepSeek 余额 ¥22.50 可覆盖**优化内容生成**；但**监测必须调 OpenAI/Google/Anthropic API**，需另开付费账号，报告估首月 $3K–8K 同样远超当前现金。
- **现金流压力：严重（阻塞级）**，与项目一同源。且 GEO 还需内容人工审计/客户沟通，隐性人力成本高。

### 2.3 竞争格局与护城河

- ✅ 蓝海判断成立：多数外贸企业不知 GEO 为何物，传统 SEO 巨头（Ahrefs/SEMrush）尚未深耕，国内海鹦云等刚起步。
- ⚠️ **窗口期 6–12 个月**是双刃剑：先占位红利大，但也意味着**市场教育成本高、销售周期长**（B2B 外贸决策慢）。
- 护城河：跨境多语种领域知识 + 早期案例库。但若 Profound/海鹦云或 SEO 巨头快速跟进，先发优势可能迅速被稀释。

### 2.4 与 SellerAI 主线协同 / 分散风险

- ✅ 内容优化复用 V1；但**目标客群不同**（B2B 外贸 vs V1 的 Amazon 卖家），获客渠道、销售话术都要重建 → **分散度高于项目一**。
- ⚠️ 同时做两个新方向，会稀释团队精力，建议二选一优先或串行。

### 2.5 评审结论：**暂缓（建议人工试点验证，暂不投入工程重build）**

理由：蓝海时机真实但窗口 + 现金 + 市场教育成本三重压力叠加；监测层有合规风险且是净新增工程；客群与 V1 偏离大。正确节奏是**用 DeepSeek + 人工查询先做 3–5 个付费案例验证需求与效果可感知性**，再决定是否投入工程 build。工程化建议排在项目一之后。

## 4. 若用户批准：第一阶段 MVP 范围 / 工期 / 资源

> 所有 MVP 均拆为 **Phase 0（验证，用现有 ¥22.50 余额）** 与 **Phase 1（注资后工程化）**，确保不先烧钱。

### 4.1 项目一 MVP

**Phase 0 — 人工替身验证（0 现金，仅耗 DeepSeek 余额）**
- 范围：用 DeepSeek 基于 V1 商品数据生成多语种脚本；人工/设计师用模板拼装 5–10 条样片；找 3–5 个 V1 老用户测付费意愿。
- 工期：1–2 周
- 资源：1 名全栈（脚本+导入复用）、1 名设计/视频（兼职）、产品兼 PM（主理人）
- 产出：付费意愿证据 + 样片 demo

**Phase 1 — 自动生成 MVP（需注资 ¥3K–7K 视频 API 测试金）**
- 范围：接入**一个**视频 API（建议先 Runway 或 Pika 单一供应商降复杂度）；Next.js UI（链接导入→脚本→生成→多尺寸导出）；异步渲染队列（Vercel Cron/Queue 或轻 Worker）；复用 V1 数据提取。
- 工期：6–8 周（非报告所说 4–6 周）
- 资源：1 名全栈（Next.js + 外部 API 集成）、1 名设计/模板、兼职 PM；外部 API 预算 $500–1000（≈¥3.5K–7K）
- 不做：多供应商冗余、重型渲染集群、完整模板库（留待 Beta）

### 4.2 项目二 MVP

**Phase 0 — 人工 GEO 审计试点（0–低现金）**
- 范围：用 DeepSeek 生成优化内容；人工向 ChatGPT/Gemini/Claude 查询并人工记录排名变化；为 3–5 个 B2B 外贸客户做付费试点报告。
- 工期：2–3 周
- 资源：1 名 GEO/SEO 专员（懂外贸）、1 名全栈（报告模板）、主理人获客
- 产出：需求真实性 + "效果可感知"证据（决定能否续费）

**Phase 1 — 监测+报告 SaaS（需注资 ¥4K–11K 监测 API 金）**
- 范围：官方 API 监测（OpenAI/Google/Anthropic，规避爬取合规风险）；Next.js 仪表盘；DeepSeek 内容优化引擎；轻量结构化知识库（先不做重图谱）。
- 工期：8–10 周
- 资源：1 名全栈、1 名 GEO 专员、兼职 PM；监测 API 预算 $500–1500（≈¥3.5K–11K）
- 不做：知识图谱重工程、代运营模块（留待后期）
