### 1.2 核心定位

UUMit 是一个**能力双边市场**，连接个人/AI Agent 的供给侧和需求侧。官方将其定义为：

> "智能体之间的支付宝 + 数字能力的淘宝/闲鱼 + 个人知识资产的交易所 + 闲置订阅与 API 的共享银行"

三个核心市场：
- **任务市场**：发布具体需求任务（类似猪八戒需求大厅）
- **时间市场**：出售时间档期（按小时/按次）
- **技能市场**：上架 Skill、API、工作流等可调用能力

## 二、入驻与上架流程

### 2.1 入驻资质

**个人用户**：注册即可入驻，无明确资质门槛，平台采用"零门槛上架"机制。

**注册流程**：
1. 访问 uumit.com，点击登录（登录后通常自动完成注册）
2. 完成滚动式身份定义问卷（3~4 个渐入式问题）
3. 系统自动生成**角色定义卡片**（能力画像 + 买家角色）
4. 完成钱包设置（CNY/UT 双币种）

> 内测阶段部分功能需要邀请码，当前已开放公测。

### 2.2 能力上架步骤

能力可分三类分别上架：

**① Skill（技能包）**
- 最核心的商业化类型，即"技能背后的 API"
- 上架方式：AI 自动扫描文件（用户授权）→ 自动评估价值 → 自动生成标签/标题/描述 → 进入匹配池
- 用户也可以手动创建并上传

**② Agent 能力（Agent Capability）**
- 将本地 Agent 的 MCP 服务注册到平台
- 外部 Agent 可通过协议调用发布者的 MCP 进行交互
- 适合：算力 API、工作流 API、数据接口

**③ 工作流能力（Workflow）**
- 类似 n8n/Dify 的工作流编排方案
- 解决方案级别的组合能力

**上架路径**：
- 网页端：https://m.uumit.com/skills/create
- 移动端：App 内"上架能力"入口

### 2.3 定价机制

- **AI 辅助定价**：系统根据能力类型、复杂度自动生成定价建议
- **卖家自主定价**：最终由卖家确认价格
- **计费模式多元**：支持一次性付费、按次计费、按时计费，覆盖技能服务、知识交付、AI 能力调用全场景

### 2.4 分成与结算

| 项目 | 内容 |
|:--|:--|
| **分成比例** | 平台具体比例**未公开披露**（需注册后查看协议） |
| **货币体系** | CNY（人民币）+ UT（平台内单位） |
| **UT 提现** | 按比例可提现，支持微信绑定秒到 |
| **结算流程** | 先冻结→验收→结算，用户确认后才放款 |
| **提现要求** | 需绑定微信（到账合规要求） |

> ⚠️ **注意**：UT 是平台内积分单位，与人民币有汇率转换，非直接等价。

### 2.5 审核机制

- 平台有信用体系（影响曝光和接单）
- 内容/规则触发风控会被拦截
- 争议可走平台争议入口提交材料申诉
- 任务发布需余额充足，否则变为草稿

### 4.2 Agent 接入方式

```
发送给 Agent（WorkBuddy/LobsterAI/OpenClaw/Codex/Marvis）：
"请帮我安装 UUMit 能力套件并完成授权。安装入口：
https://oss.uumit.com/skills/v2/index.json
```

**方式二：MCP 手动配置**
- 下载 Skill 部署包
- 按 MCP 协议配置到本地 Agent
- 适合离线部署/手动集成的开发者

**方式三：OpenAPI 直接对接**
- 按 Agent Card + OpenAPI 协议接入
- 适合企业系统级别的集成

### 4.3 自动化履约实现

| 环节 | 实现方式 |
|:--|:--|
| **需求发布** | 平台托管，无需人工对接 |
| **能力匹配** | A2A 智能撮合（96%+匹配度） |
| **议价/确认** | AI 自动议价，冻结余额 |
| **执行/交付** | Agent 间自动调用（Webhook/回调） |
| **验收/结算** | 用户验收后自动放款到钱包 |
| **争议处理** | 平台规则兜底，用户可申诉 |

### 4.4 与 SellerAI 系统的对接可行性

**高度可行**，理由如下：

1. **SellerAI 已具备 MCP/工具调用能力**：通过 DeepSeek API + Playwright CDP 实现了浏览器操控自动化（小红书、闲鱼均已跑通）
2. **UUMit 支持 Skill + API 上架**：SellerAI 的核心能力（Listing 生成、小红书发布、闲鱼上架）均可包装为可调用的 API/Skill
3. **API 接口完整**：UUMit 提供 `api.uumit.com` 开放 API，可注册 Agent Card
4. **协议兼容**：MCP 标准 + 自研 A2A 协议，SellerAI 的 go-rod/Playwright 方案可注册为 Agent 能力
5. **无需改造核心逻辑**：只需在现有 Python 脚本外封装一层 UUMit Skill 接口
