# 🔑 环境变量配置

> 环境变量 = 项目的「密码本」。不配好这些，AI 就不会工作。

---

## 什么是环境变量？

简单说：你的 API Key 是敏感信息，不能直接写在代码里（万一代码泄露，钱就被别人刷光了）。把它放到 Vercel 的「环境变量」里，代码里只写变量名，Vercel 在运行的时候自动把真实的值填进去。

---

## 第一步：获取 API Key

### DeepSeek API Key（必须）

1. 打开 https://platform.deepseek.com
2. 注册 / 登录（手机号注册就行）
3. 登录后点左侧菜单「**API Keys**」或直接打开 https://platform.deepseek.com/api_keys
4. 点「**创建 API Key**」
5. 复制弹出来的那串字符，长这样：`sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

> ⚠️ **这个 Key 只显示一次！** 复制后马上存好。丢了只能重新生成。

6. 建议先去「**充值**」页面充 5-10 块钱。不充也能用，但额度很少。

### SiliconFlow API Key（可选）

SiliconFlow 是一个国产的 AI 模型聚合平台，提供更多模型选择（比如 Llama、Qwen 等）。

1. 打开 https://siliconflow.cn
2. 注册 / 登录
3. 进入控制台 → 「**API 密钥**」
4. 点「**新建 API 密钥**」→ 复制保存

> 如果你的后端只用了 DeepSeek，不填也行。填了也不多花钱。

---

## 第二步：在 Vercel 填写环境变量

### 后端项目的环境变量

1. 打开 Vercel 控制台 → 进入 **sellerai-backend** 项目
2. 点顶部「**Settings**」
3. 左侧菜单点「**Environment Variables**」
4. 在「Key」输入框填变量名，「Value」填对应的值
5. 每填完一组，点「**Save**」
6. 所有变量填完后，去「**Deployments**」→ 找最新一条部署 → 点右边「⋯」→「**Redeploy**」

> ⚠️ 改环境变量后必须 **Redeploy** 才会生效！光保存不够！

### 前端项目的环境变量

同操作，进入 **sellerai-frontend** 项目，Settings → Environment Variables，填完之后也要 Redeploy。

---

## 第三步：完整环境变量对照表

### 后端 `sellerai-backend` 需要配的变量

| 变量名 | 值从哪来 | 示例值 | 必填 |
|--------|---------|--------|------|
| `DEEPSEEK_API_KEY` | https://platform.deepseek.com/api_keys | `sk-abc123def456...` | ✅ 必须 |
| `DEEPSEEK_BASE_URL` | DeepSeek 默认 API 地址 | `https://api.deepseek.com` | 不用填也行 |
| `SILICONFLOW_API_KEY` | https://siliconflow.cn | `sk-xxxxx...` | ❌ 可选 |
| `SILICONFLOW_BASE_URL` | SiliconFlow 默认 API 地址 | `https://api.siliconflow.cn/v1` | 不用填也行 |

### 前端 `sellerai-frontend` 需要配的变量

| 变量名 | 值从哪来 | 示例值 | 必填 |
|--------|---------|--------|------|
| `NEXT_PUBLIC_API_URL` | 后端项目部署后 Vercel 给你的地址 | `https://sellerai-backend-xxxxx.vercel.app` | ✅ 必须 |

> 📌 `NEXT_PUBLIC_API_URL` 填的是后端的地址，**不是**前端的地址！别搞混。

---

## 环境变量填写的注意事项

### ✅ DO（这样做）

- 复制 API Key 时别带前后空格
- 变量名全大写（照抄上面的表，大小写敏感）
- 改完后一定 Redeploy
- API Key 值要复制完整（通常以 `sk-` 开头）

### ❌ DON'T（别这样做）

- 别把 API Key 截图发给别人
- 别把 API Key 写到代码里提交到 GitHub
- 别在公开场合分享你的 .env 文件
- 别在同一个项目里重复填（Key 填在后台就行，前台不直接调 AI）

---

## 怎么检查环境变量有没有生效？

### 方法一：看 Vercel 部署日志

进入项目 → Deployments → 点最新那条 → 看 Build Log。如果没有报「找不到环境变量」之类的错误，一般就没问题。

### 方法二：直接测试

打开你的网站 → 在聊天框发一条消息 → 如果 AI 回复了，说明环境变量配置正确。

如果 AI 不回复：
1. 按 F12 打开浏览器开发者工具
2. 点「Network」标签
3. 刷新页面，发一条消息
4. 看有没有红色的请求（状态码 500 或 CORS 错误）
5. 有报错 → 进 Vercel 后端项目 → Deployments → 看「Runtime Logs」里的错误信息

---

## 环境变量填错了怎么改？

1. 回到 Settings → Environment Variables
2. 找到填错的变量，点右边的编辑图标
3. 改好后点 Save
4. **Redeploy！Redeploy！Redeploy！**（重要的事说三遍）

---

## 补充：不同类型的变量区别

| 前缀 | 含义 | 用在哪儿 |
|------|------|---------|
| 没有前缀 | 只有后端能读 | 后端项目 |
| `NEXT_PUBLIC_` | 前端代码里也能读 | 前端项目 |

所以前端的变量名必须带 `NEXT_PUBLIC_` 前缀，不然前端代码读不到。`DEEPSEEK_API_KEY` 不带前缀，只给后端用，更安全。

---

以上！配完环境变量 + Redeploy 后，你的 AI 网站就能正常说话了 🎉
