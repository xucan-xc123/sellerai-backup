# 竞品应对改造部署记录 2026-07-19

## 背景
竞品调研发现 PowerListing（$39/mo，ASIN 输入首屏截流）、Perci.ai、Sellesta 等直接竞争。瓶颈：首页无交互入口、定价偏低。

## 改动清单

### 1. Hero 标题与数据微章（Hero.tsx）
- 标题从「Amazon Best Seller」改为多平台展示：「Amazon, eBay, Walmart, Shopify, TikTok Shop & Etsy」
- 新增信任数据微章行：🌍15 Marketplaces / 🗣️9 Languages / 🛒6 Platforms / ⚡~10s Generation
- CTA 按钮文案改为「Try Free — No Signup」
- 附带第二个「Start Generating」同行按钮

### 2. 首页嵌入免费工具（page.tsx）
- 在 Hero 下方直接嵌入 `<ListingGenerator />` 组件
- 用户无需点击任何按钮，滚动即可输入产品描述、选择平台、生成 Listing
- 对标 PowerListing 首屏 ASIN 输入框的截流策略

### 3. 对比表新增 PowerListing 行（ComparisonTable.tsx）
- 列头新增「PowerListing」列
- 行从4行扩展到7行：Price / Platforms covered / Input languages / Output languages / Speed / Focus / Best for
- 价格从 $19.9 更新为 $24.9

### 4. 定价调整（Pricing.tsx）
- Starter: $19.9/mo → **$24.9/mo**（+25%，缩小与 $39 竞品差距）
- 年付: $119/yr → **$199/yr**（折扣从~50%缩至~33%）
- Founder 价格 $14.9 维持不变（老用户锁价）

### 5. 关键词搜索量估计（API prompt + 前端显示）
- API prompt 新增指令：每个关键词附带 `est_volume`（月搜索量估计）
- 后端新增 keywords 归一化逻辑（兼容 string[] 和 {keyword, est_volume}[] 两种格式）
- 前端 Keywords 显示改为 Chip + 搜索量徽章格式：`keyword ✦ ~28,000/mo`
